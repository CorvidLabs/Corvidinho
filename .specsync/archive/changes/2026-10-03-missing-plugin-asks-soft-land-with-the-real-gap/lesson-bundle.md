# Lessons

- A named missing plugin should soft-land with the real gap (not installed, not allowlisted, not configured, role, or tier) and cite an HI id or open PR only when a lookup returned it.
- Do not invent a provider (Tenor or otherwise) and do not ask what to install when the message already names the plugin. Community sessions stay read/chat.
- Squash-merge orphans SpecSync finalize when archive post-move hits an earlier tip-orphan whose verification commit is not in history; tip-orphan archive like #359.
